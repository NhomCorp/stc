Cách lấy Meta Access Token (System User)

Nên dùng System User trong Business Manager — ổn định cho job GAS định kỳ. Không dùng token login Facebook thường ngày.
  1. Mở Meta Business Settings → Users → System users.
  2. Tạo System User (hoặc chọn sẵn) → Add assets → chọn Ad account cần đối soát → quyền xem/đọc ads (View performance).
  3. Bấm Generate token → chọn Meta App → tick quyền ads_read → Generate.
  4. Copy token → dán vào ô Meta Access Token bên dưới.
  5. Ad Account ID: Ads Manager → chọn account → URL có act=123… → điền act_123….
  6. Nếu account thuộc Business Manager: Business Settings → lấy Business ID → ô Business ID (thường cần để API trả billing).
  7. Lookback nên ≥ 30–60 ngày nếu đang đối soát bill sót.
  8. Bấm Check live → thấy API OK → Lưu cấu hình. Nếu charges=0: chạy debugMetaBillingActivities trên Editor.
Token coi như mật khẩu. Hết hạn / bị revoke → Generate lại và dán đè. Chi tiết API: activities ad_account_billing_charge.
